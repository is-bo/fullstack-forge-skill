# Brand assets

Fullstack Forge uses an original “modular forge” concept: layered software plates move through a
precision anvil and emerge as an evidence seal. The visual language is industrial without nostalgia,
and technical without generic neon-AI imagery.

## Files

| Asset                                | Dimensions | Use                                                  |
| ------------------------------------ | ---------- | ---------------------------------------------------- |
| `fullstack-forge-hero.png`           | 1600 × 900 | README, launch pages, presentations                  |
| `fullstack-forge-social-preview.png` | 1280 × 640 | GitHub social preview and link cards                 |
| `fullstack-forge-icon.png`           | 512 × 512  | Agent metadata, repository avatar, square thumbnails |

## System

- Ink: `#F8FAFC`
- Graphite: `#0F172A`
- Slate: `#334155`
- Cobalt evidence line: `#2563EB`
- Ember inspection accent: `#F97316`
- Headings: a strong neutral grotesk/sans serif.
- Technical labels: a legible monospace.

The committed raster assets use Segoe UI Bold and Cascadia Mono, rendered into the images; no font
files are distributed.

## Usage

Keep the full frame, safe margins, aspect ratio, and color relationship. Do not recolor vendor
logos, add third-party endorsement, place low-contrast text over the forge, stretch the art, crop
away the evidence seal, or use the icon as proof of certification. The phrase “evidence before
confidence” is a product principle, not a compliance claim.

The background illustration was generated with the built-in OpenAI image-generation tool from an
original project prompt, then cropped, typeset, and dimensioned locally. No third-party logo, image,
or font binary was used.
