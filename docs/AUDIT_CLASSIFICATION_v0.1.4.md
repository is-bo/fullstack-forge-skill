## Additional issues discovered

| Issue                                                                        | Classification | Resolution                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ordinary exported functions reported as tenant background jobs               | CONFIRMED      | Background-job detection now uses path and function semantics rather than the `export` keyword; regression coverage preserves genuine worker findings.                                                                                                                          |
| Raw SQL `.query` treated as an authorization object lookup                   | CONFIRMED      | Authorization object lookup recognition now requires a supported data-access object shape; SQL remains under the injection analyzer.                                                                                                                                            |
| Public finding JSON Schema rejected runtime `instance_id` and `fix_attempts` | CONFIRMED      | Schema and runtime validation now define instance IDs, scoped verification actions, and fix attempts; malformed cross-instance scopes are rejected.                                                                                                                             |
| Code scanning had no analysis                                                | CONFIRMED      | Added a least-privilege, immutable-SHA CodeQL JavaScript/TypeScript workflow using `build-mode: none`. Remote results remain pending until PR/main execution.                                                                                                                   |
| Future releases were not immutable                                           | CONFIRMED      | The repository immutable-release setting was disabled. It was enabled and read back through the authenticated repository API; prior releases were not modified.                                                                                                                 |
| Typed protection survived a later raw reassignment                           | CONFIRMED      | Protection merging initially used a union, so an allowlisted destination could bless a later request-controlled reassignment. Assignment protection now intersects across reaching writes; the raw-reassignment SSRF test fails safely.                                         |
| Conditional or non-dominating authorization counted as proof                 | CONFIRMED      | An authorization call inside an unrelated conditional and a branch that did not exit could protect a later lookup. Only unconditional enforcing calls or guards whose denial branch dominates by exiting count; negative analyzer tests cover both shapes.                      |
| Same-scope occurrence identity shifted after a peer fix                      | CONFIRMED      | The occurrence discriminator counted only currently unresolved issues, so fixing the first identical sink renumbered its peer. Identity now counts every matching structural sink node, including safe peers; stability is regression-tested.                                   |
| Fix and verify could leave stale report lifecycle evidence                   | CONFIRMED      | Report revision was not recomputed after writes, verification discarded prior typed gate/coverage evidence, and rollback omitted a `ROLLED_BACK` attempt. Each transition now recomputes revision, preserves evidence, and records exact-instance rollback state.               |
| Coverage parsing was platform-sensitive                                      | CONFIRMED      | The parser recognized one mojibake rendering of Node's information prefix but not the native Unicode prefix emitted on other hosts. It accepts both while preserving table indentation; parser tests cover each representation.                                                 |
| Draft release verification omitted candidate assets                          | CONFIRMED      | An intermediate release design attested only ZIPs and compared neither the exact asset set nor `manifest.json`. The final workflow attests every initial candidate asset and requires exact names plus byte-identical ZIP, checksum, and manifest downloads before publication. |
| Secret scan crashed on deleted tracked paths                                 | CONFIRMED      | `git ls-files --cached --others` includes unstaged tracked deletions, and unconditional `lstat` aborted the scan during fixture renames. The scanner subtracts Git's deleted set while retaining untracked files; a temporary-repository regression test proves both cases.     |

## Boundaries retained as NOT_VERIFIED

- The TypeScript analyzer is bounded and intra-file; dynamic dispatch, reflective calls, and
  cross-module value flow are not claimed sound.
- Python, Go, Rust, and JVM adapters are named gaps, not simulated coverage.
- Browser, assistive-technology, database, provider, malware-scanner, infrastructure, and production
  state require direct runtime or operator evidence.
- GitHub CI, CodeQL, dependency review, publication, provenance, and release immutability are
  pending in tagged source and become authoritative only through the linked remote runs.
- Forge's bounded static analyzers inspect deliberately vulnerable source strings in `cli/tests` as
  executable-looking code. Self-audit therefore remains fail-closed on those six high test-fixture
  findings; this is not treated as runtime proof or silently excluded.
