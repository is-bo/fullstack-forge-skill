## Project profile

Summarize detected applications, boundaries, confidence, and evidence.

## Findings

For each finding include ID, module, producer, evidence type, title, severity, confidence, status,
locations, evidence, explanation, impact, recommendation, safe-fix classification, verification,
revision, commands executed, remaining limitations, and standards.

## Prioritized remediation

Order by severity, confidence, impact, then effort. Separate safe fixes from approval-required work.

## Execution ledger

List commands, exit codes, relevant output, failures, skipped checks, unavailable tools,
assumptions, and residual risk. Never omit a failed gate.
